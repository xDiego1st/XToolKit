# Catatan Rilis v1.0.1 — XToolKit-Diego

[Pusat Dokumentasi](../README.md) · [README Utama](../../README.md)

Pembaruan pemeliharaan, keamanan, dokumentasi, dan keandalan sejak rilis sumber **1.0.0**.

---

## Sorotan Perubahan

- **Diagnostik Google Play lebih aman:** menghapus salinan sementara basis data Play Store segera setelah pembacaan token pembelian selesai, termasuk ketika terjadi kegagalan.
- **Validasi laporan checkout lebih ketat:** menolak laporan lama (*stale*), ambigu, atau milik akun berbeda agar tidak dianggap hasil terverifikasi; memisahkan file laporan per akun menggunakan hash akun yang dinormalisasi.
- **Peningkatan keamanan interaksi:** konfirmasi manual Android kini gagal secara aman (*fail-closed*) saat timeout/EOF; tidak pernah mengisi alamat tagihan palsu, melakukan quoting karakter khusus pada input ADB, dan tidak menuliskan kode 2FA ke dalam log.
- **Status TUI lebih bersih:** mereset status perangkat, akun, dan output teknis setiap kali menjalankan pemeriksaan baru.
- **Cakupan pengujian lebih baik:** penambahan uji regresi Unicode Windows serta pembaruan dokumentasi dan pengujian otomatis offline.

---

## Menjalankan Rilis Sumber

Ekstrak arsip kode sumber ke folder terpisah, pastikan **MuMuPlayer** (Windows) atau **Android SDK Platform-Tools + emulator/perangkat ber-root** (macOS) sudah siap, lalu jalankan:

**macOS (Terminal):**

```sh
sh run-macos.sh
```

**Windows (PowerShell):**

```powershell
.\run-all.ps1
```

Atau jalankan cek daftar penawaran tanpa membuka dasbor:

```sh
# macOS
sh run-macos.sh --list
```

```powershell
# Windows
.\run-all.ps1 -Step 1
```

> Arsip kode sumber **bukan file installer `.exe` maupun `.app` siap pasang**; tetap membutuhkan Python 3.10+, ADB, Frida 16.5.9, dan perangkat/emulator Android ber-root.

## Batasan Pengujian & Peringatan

- Pengujian otomatis (unit test / CI) hanya menjalankan simulasi (*mock*) untuk Python, PowerShell, Textual, dan hook Frida — **tidak pernah menjalankan transaksi Google Play sungguhan**.
- Kompatibilitas perangkat keras nyata (Windows/MuMu maupun macOS/Android) harus diverifikasi langsung pada perangkat masing-masing (lihat [Daftar Periksa Uji Coba Windows](../WINDOWS-SMOKE-TEST.md)).
- **Step 2–4 dapat memicu biaya/verifikasi pembayaran nyata.** Daftar penawaran, tampilan Rp0/US\$0, maupun terbukanya layar Google Play Billing bukan bukti kelayakan atau keberhasilan perpanjangan. Selalu cek langsung di Google Play dan baca [Penafian Lengkap](../../DISCLAIMER.md).
